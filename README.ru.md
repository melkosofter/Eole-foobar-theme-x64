# Eole x64 — полная инструкция установки

Неофициальная адаптация [оригинальной темы Eole](https://github.com/Ottodix/Eole-foobar-theme) для **foobar2000 2.x, 64-bit**. Проверенная комбинация: **foobar2000 2.26.1 x64, Windows 11**. Для 32-битного плеера используйте исходную тему.

## 1. Скачать комплект

В [Releases](https://github.com/melkosofter/Eole-foobar-theme-x64/releases/latest) скачайте `Eole-foobar-theme-x64-1.0.0-full.zip` и распакуйте в отдельную папку. Архив содержит все компоненты x64, тему, раскладку, 552 пресета MilkDrop и последние исправления окна. SHA-256 архива указан в `SHA256SUMS.txt` рядом с ним.

Плеер скачайте с [официального сайта](https://www.foobar2000.org/download), выбирая **64-bit / x64**. Сам установщик foobar2000 в комплект темы не включён. На Windows 11 модуль оформления рамки использует .NET Framework 4.x.

## 2. Найти папку профиля и сделать резервную копию

Закройте foobar2000 через File → Exit. В том числе закройте экземпляры в трее.

| Тип установки | Обычное расположение профиля |
|---|---|
| Стандартная установка foobar2000 2.x | `%APPDATA%\foobar2000-v2` |
| Portable | `<папка плеера>\profile` |
| Microsoft Store / нестандартная установка | Уточните фактический профиль; стандартный путь может отличаться |

В Проводнике можно вставить `%APPDATA%\foobar2000-v2` в адресную строку. Каталог `C:\Program Files\foobar2000` содержит сам плеер, **а не пользовательскую тему**.

Скопируйте весь текущий профиль в отдельную папку. Такая копия сохраняет настройки, плейлисты и статистику. Дополнительно экспортируйте старую конфигурацию Columns UI через Preferences → Display → Columns UI → Export configuration. Импорт Eole заменяет текущую раскладку интерфейса.

## 3. Установить файлы

Выберите один способ.

### Способ A: вручную

Из распакованной сборки скопируйте **содержимое следующих четырёх папок** в соответствующие папки профиля, объединяя каталоги:

```text
<профиль>\
  themes\eole\                    ← тема, скрипты, изображения, FCL и EoleBorder
  user-components-x64\            ← семь папок компонентов и их зависимости
  milkdrop2\                      ← data, presets, textures, docs
  wsh-data\eole-settings\         ← THEMEVERSION_1.2.3b24
```

Не создавайте дополнительный уровень `Eole-foobar-theme-x64` внутри профиля. Итоговый путь к раскладке должен быть `<профиль>\themes\eole\columnsUI_eole_x64.fcl`.

При обновлении уже установленного Eole оставьте остальные файлы `wsh-data\eole-settings` как есть. Сохраните старые файлы `THEMEVERSION_*` в резервной копии, уберите их из рабочей папки и поместите только `THEMEVERSION_1.2.3b24`. Несколько маркеров одной настройки создают неоднозначность.

В папках компонентов должны остаться обе зависимости движков:

```text
user-components-x64\foo_uie_jsplitter\mozjs-lur-153.dll
user-components-x64\foo_spider_monkey_panel\mozjs-102.dll
```

Нулевой файл `user-components-x64\foo_uie_eslyric\enable_script_control` необходим для управления ESLyric из темы. Он уже включён. В OpenHacks должна использоваться **DLL из этой сборки**: она исправлена для класса окна Columns UI.

### Способ B: установочный скрипт

Откройте PowerShell в распакованной папке и выполните:

```powershell
.\install.ps1 -ProfilePath "$env:APPDATA\foobar2000-v2"
```

Для portable:

```powershell
.\install.ps1 -ProfilePath 'D:\Players\foobar2000\profile'
```

Проверить комплект без записи файлов:

```powershell
.\install.ps1 -ProfilePath "$env:APPDATA\foobar2000-v2" -ValidateOnly
```

Скрипт проверяет контрольные суммы, требует закрыть плеер, копирует только известные папки сборки и сохраняет заменяемые файлы в `<профиль>\eole-install-backups\<дата-время>`. Статистика, медиатека, плейлисты и прочая конфигурация не переносятся из чужого профиля. Импорт FCL остаётся отдельным ручным шагом.

Если Windows отметила распакованный ZIP как загруженный из Интернета и блокирует `.ps1`, сначала изучите скрипт, затем снимите блокировку у него через Properties → Unblock. Не нужно глобально отключать защиту или менять политику Windows ради темы. Вручную установить файлы можно без запуска скрипта.

## 4. Включить Columns UI и импортировать тему

1. Запустите foobar2000. В первом диалоге выбора интерфейса укажите **Columns UI**. Если плеер открывает другой интерфейс, перейдите File → Preferences → Display, выберите Columns UI и перезапустите при запросе.
2. В Preferences → Components проверьте наличие семи компонентов из таблицы ниже. Отсутствие JSplitter обычно означает неверную папку профиля, x86-версию плеера или потерянную DLL движка.
3. Откройте Preferences → Display → Columns UI. Нажмите **Import configuration / Import** и выберите `<профиль>\themes\eole\columnsUI_eole_x64.fcl`. Название вкладки с кнопкой Import может зависеть от версии Columns UI.
4. Подтвердите импорт и закройте Preferences кнопкой OK. Если интерфейс не обновился сразу, один раз перезапустите плеер.
5. При первом запуске Eole может предложить настройки кэша обложек и памяти. Начните с предлагаемых значений, затем настройте их под размер своей медиатеки.

Не импортируйте FCL из оригинальной сборки x86 и не копируйте старый `foo_ui_columns.dll.cfg` поверх рабочей конфигурации. Оба FCL-файла **в этом форке** содержат x64-раскладку; предпочтительный файл имеет суффикс `_x64`.

| Компонент | Проверенная версия |
|---|---|
| Columns UI | 3.7.0 x64 |
| JSplitter | 4.3.4 x64 |
| Spider Monkey Panel | 1.7.26.5.1 x64 |
| OpenHacks | 0.1.5 x64 + патч Columns UI |
| ESLyric | 1.0.7.0 x64 |
| Playback Statistics | 3.1.10 x64 |
| MilkDrop 2 Visualisation | 0.9.16 x64 |

## 5. Настроить музыку и визуализацию

В Preferences → Media Library добавьте свои папки с музыкой и дождитесь сканирования. Это личная настройка; комплект её не задаёт.

Запустите трек и откройте вкладку **Visualization**. В ней встроен нативный MilkDrop x64. Настраивать Winamp или Shpeck не нужно. В настройках MilkDrop путь пресетов должен указывать на:

```text
%fb2k_profile_path%\milkdrop2\presets\
```

Этот относительный к профилю путь уже сохранён в x64 FCL. Каталог `milkdrop2\data` содержит шейдеры именно нативного компонента; старые шейдеры Winamp поверх него не копируйте. Текстуры лежат рядом в `milkdrop2\textures`. Если визуализация пуста, проверьте воспроизведение, расположение пресетов и настройки графического устройства MilkDrop.

## 6. Верхняя панель, темы, биография и тексты

- Вверху слева **Foobar** открывает меню плеера. Свободную область верхней полосы между меню и оконными кнопками можно захватывать мышью и перетаскивать окно.
- Кнопка переключения светлой/тёмной темы меняет оформление текущего раздела; двойное нажатие переключает тему глобально, согласно поведению Eole.
- Возвращены кнопки полного экрана, информации о треке, настройки раскладки и правой панели.
- В Windows 11 внешний контур отключён в обеих темах. Верхняя системная полоса окрашена под Eole; скругления сохраняются. Нижний отступ и правая полоса устранены пересчётом размера панелей.
- Стрелка над изображением в **Now playing** — меню **Look up…** панели Biography. Оно позволяет выбирать связанные данные исполнителя/альбома. Среднее нажатие блокирует обновление при смене трека, если выбранный источник это поддерживает; вместо стрелки отображается замок. Эти две иконки теперь рисуются векторно, установка FontAwesome для них не нужна.
- Источники текстов настраиваются в Preferences → Tools → ESLyric. При необходимости обновите/выберите источники через настройки компонента. Внешние сайты могут отдавать переводы или перестать отвечать; состав источников и доступность текстов не гарантируются темой.
- Биографии и фотографии используют внешние сервисы. При изменении обложек очистите соответствующий кэш через контекстное меню → Refresh this image.

## 7. Обновление и откат

При обновлении закройте плеер и сохраните профиль. Обновите файлы темы и компонентов из нового архива. Повторный импорт FCL требуется при изменении раскладки или для восстановления исходных настроек; он может сбросить ваши изменения панелей.

Для полного отката закройте плеер и восстановите сохранённый до установки профиль. Для отката только файлов скриптов/компонентов используйте резервную папку установщика и копируйте её содержимое по тем же относительным путям. Новые папки, которых до установки не было, в резервную копию не входят; при полном удалении темы их нужно убрать отдельно. Старую раскладку верните импортом своего экспортированного FCL. Резервная копия всего профиля — самый надёжный способ вернуть исходное состояние.

## 8. Диагностика и ограничения

| Симптом | Что проверить |
|---|---|
| Тема не появилась | Правильный профиль, Columns UI выбран, x64 FCL импортирован |
| Unknown panel / отсутствуют панели | Все компоненты x64 и DLL движков на месте; затем перезапуск |
| Ошибка ActiveXObject ESLyric | Компонент ESLyric x64 и файл `enable_script_control`; перезапуск |
| Окно не перетаскивается | Локальная DLL OpenHacks из комплекта; интерфейс Columns UI |
| Вернулась рамка/пустой низ | `themes\eole\tools\EoleBorder.exe` сохранён, .NET Framework доступен, файл не блокируется Windows |
| Предложение импортировать старую тему | Оставлен только `THEMEVERSION_1.2.3b24`; импортируйте FCL из этого форка |
| Нет текстов/биографии | Воспроизведение, теги, сеть и источники соответствующего компонента |
| MilkDrop не рисует | Воспроизведение, x64 компонент, пресеты, шейдеры data, графические настройки |

**Shpeck не переписан:** вместо загрузки 32-битных Winamp-плагинов используется нативный MilkDrop x64. Поддержки других старых Winamp-плагинов нет. Новый контроллер воспроизводит структуру Eole, но не все функции Panel Stack Splitter. Автоматическое изменение минимального/максимального размера окна и автоматическое уменьшение mini mode из UIHacks не перенесены; размер меняется вручную. OpenHacks в комплекте рассчитан на Columns UI, не на Default UI. На старых версиях Windows часть оформления DWM недоступна.
